# Auto Render Tool v8

**Made by Minh Thi**

Auto Render Tool is a lightweight desktop utility designed to simplify repetitive post-render tasks during animation and cinematic production.

## Main Features

1. Convert image sequences (`.png`, `.jpg`, `.jpeg`, `.exr`) into a single video.
2. Merge multiple video files (`.mp4`, `.mov`, etc.) into one final video.

## How to Use

### Step 1
Download `Auto Render v8.exe` and double-click it to launch the tool.

### Step 2
Inside the application:

- Select a mode:
  - **Image Sequence Render**
  - **Video Merge**
- Click **Select** and choose the folder containing your files.
- Select your desired **FPS**.
- Select the encoding option that matches your computer configuration.

### Step 3
Click **RENDER** and let the tool handle the rest.

Once processing is complete, the output video will be saved directly inside the folder you selected.
